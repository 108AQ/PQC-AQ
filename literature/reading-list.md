# Reading list

## dLIN

- [ ] **ABW** Applebaum, Barak, Wigderson, *Public-Key Cryptography from Different
  Assumptions* (2009). `literature/dLIN/applebaum-barak-wigderson-2009-pke-from-different-assumptions.pdf`.
  Bib key `abw2010pke`. Start at §7 (PKE from d-LIN and decisional unbalanced expansion)
  and §9 (unconditional hardness of d-LIN); §5-6 cover PKE from 3-LIN.

## Kyber

- [ ] **Kyber v3.02** Avanzi et al., *CRYSTALS-Kyber Algorithm Specifications and
  Supporting Documentation* (2021). `literature/kyber/crystals-kyber-spec-v3.02-2021.pdf`.
  Bib key `kyber2021spec`. NIST Round 3 submission; the scheme later standardised as ML-KEM.

## ML-KEM

- [ ] **FIPS 203** NIST, *Module-Lattice-Based Key-Encapsulation Mechanism Standard* (2024).
  `literature/mlkem/nist-fips-203-ml-kem.pdf`. Bib key `fips203`. The normative standard;
  compare against Kyber v3.02 for the changes made during standardisation.

## Common

- [ ] **Menezes** *A Gentle Introduction to Lattice-Based Cryptography*, v2.1 (2026).
  `literature/common/menezes-2026-gentle-intro-lattice-crypto-v2.1.pdf`. Bib key
  `menezes2026lattice`. Background on lattices, Kyber/ML-KEM, Dilithium and Falcon;
  good first read before the Kyber spec.
